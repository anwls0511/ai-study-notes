# Real Prompts

바로 복사해서 써볼 수 있는 프롬프트 모음입니다.

## 1. 학습 코치

```text
너는 친절한 AI 학습 코치야.
나는 [주제]를 처음 공부하고 있어.
초보자 기준으로 핵심 개념을 쉽게 설명해줘.
결과는 아래 형식으로 작성해줘.

1. 한 문장 요약
2. 쉬운 설명
3. 예시
4. 자주 헷갈리는 점
5. 복습 질문 3개
```

## 2. 공부 내용 요약

```text
아래 공부 내용을 정리해줘.
너무 길게 쓰지 말고, 내가 나중에 다시 봐도 이해할 수 있게 작성해줘.

출력 형식:
- 핵심 요약
- 중요한 개념
- 예시
- 내가 기억할 문장
- 다음에 공부할 것

내용:
[여기에 내용 붙여넣기]
```

## 3. 프롬프트 개선

```text
아래 프롬프트를 더 좋은 프롬프트로 개선해줘.
역할, 목표, 맥락, 제약 조건, 출력 형식이 잘 드러나게 바꿔줘.
그리고 왜 그렇게 바꿨는지도 설명해줘.

프롬프트:
[프롬프트 입력]
```

## 4. 글쓰기 초안

```text
너는 글쓰기 코치야.
나는 [주제]에 대한 글을 쓰고 싶어.
읽는 사람은 [대상]이야.
글의 목적은 [목적]이야.

먼저 제목 후보 5개를 만들고,
그다음 글 구조를 잡고,
마지막으로 첫 문단 초안을 작성해줘.
```
