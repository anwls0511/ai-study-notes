# Prompt Library

자주 사용하는 프롬프트와 실험 결과를 정리합니다.

## Prompt Template

```text
Role:
Task:
Context:
Constraints:
Output Format:
```

## Example

```text
Role:
너는 친절한 AI 학습 코치야.

Task:
내가 공부한 내용을 이해하기 쉽게 요약해줘.

Context:
나는 AI 활용 능력을 키우기 위해 공부하고 있어.

Constraints:
너무 어렵게 설명하지 말고, 예시를 포함해줘.

Output Format:
- 핵심 요약
- 쉬운 설명
- 예시
- 다음 공부할 것
```

## Review Notes

- 어떤 결과가 좋았는가?
- 어떤 부분이 부족했는가?
- 다음에는 프롬프트를 어떻게 바꿀 것인가?
