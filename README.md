# ai-study-notes

AI를 막연히 써보는 수준에서 벗어나, 실제 문제 해결 도구로 활용하기 위해 쌓아가는 AI 활용 학습 기록입니다.

## 학습 질문

```text
AI에게 질문했는데 답변이 애매한 이유는 뭘까?
좋은 프롬프트와 나쁜 프롬프트는 무엇이 다를까?
역할, 목표, 맥락, 출력 형식은 왜 중요할까?
AI 답변을 그대로 믿지 않고 검토하려면 어떻게 해야 할까?
반복 작업을 AI 워크플로우로 만든다는 건 무슨 뜻일까?
공부, 글쓰기, 코딩 보조에 AI를 어떻게 활용할 수 있을까?
개발자는 코드 이해, 디버깅, 리팩터링에 AI를 어떻게 활용할 수 있을까?
개발 작업 전체 흐름에 AI를 어떻게 끼워 넣을 수 있을까?
좋은 프롬프트를 한 번 쓰고 버리지 않고 어떻게 자산으로 쌓을 수 있을까?
AI 답변이 믿을 만한지 어떻게 판단할 수 있을까?
AI와 내가 각각 맡아야 할 역할은 어떻게 나눌 수 있을까?
```

## 프롬프트 실습

```text
너는 친절한 AI 학습 코치야.
나는 AI 활용을 처음 공부하고 있어.
좋은 프롬프트를 만드는 핵심 원칙을 초보자 기준으로 설명해줘.
결과는 한 줄 요약, 쉬운 설명, 예시, 연습 문제 순서로 작성해줘.
```

```text
너는 초보 개발자를 도와주는 선배 개발자야.
아래 작업 요구사항을 읽고 바로 코드를 작성하지 말고,
먼저 작업 목표, 확인해야 할 조건, 구현 순서, 테스트할 내용을 정리해줘.

요구사항:
[여기에 요구사항 붙여넣기]
```

```text
아래 프롬프트를 내 프롬프트 라이브러리에 저장할 수 있게 정리해줘.
목적, 사용할 상황, 프롬프트, 개선 포인트, 태그로 나눠줘.

프롬프트:
[여기에 프롬프트 붙여넣기]
```

## 실행 결과 예시

```text
개발 작업 흐름:
1. 요구사항을 AI에게 요약시킨다.
2. 구현 전에 확인 질문을 뽑는다.
3. 작업 계획과 테스트 케이스를 만든다.
4. 코드를 작성한 뒤 AI에게 리뷰 관점으로 검토시킨다.
5. 최종 판단은 개발자가 직접 한다.

프롬프트 라이브러리:
- 한 번 쓴 좋은 프롬프트는 목적과 사용 상황을 함께 저장한다.
- 결과가 별로였던 프롬프트도 개선 기록으로 남긴다.
- 자주 쓰는 프롬프트는 템플릿으로 만든다.
```
