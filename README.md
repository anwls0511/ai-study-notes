# ai-study-notes

AI를 막연히 써보는 수준에서 벗어나, 실제 문제 해결 도구로 활용하기 위해 쌓아가는 AI 활용 학습 기록입니다.

## 학습 질문

```text
AI에게 질문했는데 답변이 애매한 이유는 뭘까?
좋은 프롬프트와 나쁜 프롬프트는 무엇이 다를까?
역할, 목표, 맥락, 출력 형식은 왜 중요할까?
AI 답변을 그대로 믿지 않고 검토하려면 어떻게 해야 할까?
반복 작업을 AI 워크플로우로 만든다는 건 무슨 뜻일까?
공부, 글쓰기, 코딩 보조에 AI를 어떻게 활용할 수 있을까?
개발자는 코드 이해, 디버깅, 리팩터링에 AI를 어떻게 활용할 수 있을까?
```

## 프롬프트 실습

```text
너는 친절한 AI 학습 코치야.
나는 AI 활용을 처음 공부하고 있어.
좋은 프롬프트를 만드는 핵심 원칙을 초보자 기준으로 설명해줘.
결과는 한 줄 요약, 쉬운 설명, 예시, 연습 문제 순서로 작성해줘.
```

```text
아래 AI 답변을 검토해줘.
확실한 내용, 확인이 필요한 내용, 틀릴 가능성이 있는 내용을 구분해줘.
그리고 내가 추가로 확인해야 할 질문 3개를 만들어줘.

AI 답변:
[여기에 AI 답변 붙여넣기]
```

```text
너는 초보 개발자를 도와주는 선배 개발자야.
아래 코드를 읽고 무엇을 하는 코드인지 설명해줘.
함수별 역할, 전체 흐름, 주의할 점을 나눠서 알려줘.

코드:
[여기에 코드 붙여넣기]
```

## 실행 결과 예시

```text
한 줄 요약: 좋은 프롬프트는 AI가 해야 할 일과 답변 형식을 분명하게 알려주는 지시문이다.

AI 답변 검토:
- 확실한 내용과 추측을 구분한다.
- 최신 정보가 필요한 내용은 따로 확인한다.
- 중요한 판단에는 근거와 출처를 요구한다.

개발자 활용:
- 코드를 대신 맡기기보다 이해, 디버깅, 리뷰, 테스트 아이디어에 활용한다.
- AI가 만든 코드는 반드시 직접 읽고 실행해서 검증한다.
```
