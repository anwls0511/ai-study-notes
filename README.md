# AI Study Notes

AI 활용 공부하며 정리하는 저장소입니다.

## Goals

- AI 도구를 일상과 업무에 효과적으로 활용한다.
- 좋은 프롬프트를 작성하고 개선하는 방법을 익힌다.
- 반복 작업을 AI 워크플로우로 정리한다.
- 공부한 내용을 노트, 프롬프트, 실습 기록으로 남긴다.
- AI를 단순히 사용하는 것을 넘어 문제 해결 도구로 활용한다.

## Study Areas

### 1. Prompting

역할, 목표, 맥락, 제약 조건, 출력 형식을 명확히 전달하는 방법을 공부합니다.

### 2. AI Workflows

요약, 글쓰기, 기획, 자료 정리, 코딩 보조, 학습 도우미 등 반복 가능한 활용 흐름을 정리합니다.

### 3. Practice Notes

직접 사용해본 프롬프트, 결과, 개선점을 기록합니다.

## Repository Structure

```text
prompts/   자주 쓰는 프롬프트와 실험 기록
notes/     AI 활용 방법과 개념 정리
examples/  실제 활용 사례와 결과 정리
```

- AI 활용 사례 정리하기
- 나만의 프롬프트 라이브러리 만들기
