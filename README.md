# ai-study-notes

AI를 막연히 써보는 수준에서 벗어나, 실제 문제 해결 도구로 활용하기 위해 쌓아가는 AI 활용 학습 기록입니다.

## 학습 질문

```text
AI에게 질문했는데 답변이 애매한 이유는 뭘까?
좋은 프롬프트와 나쁜 프롬프트는 무엇이 다를까?
역할, 목표, 맥락, 출력 형식은 왜 중요할까?
AI 답변을 그대로 믿지 않고 검토하려면 어떻게 해야 할까?
반복 작업을 AI 워크플로우로 만든다는 건 무슨 뜻일까?
공부, 글쓰기, 코딩 보조에 AI를 어떻게 활용할 수 있을까?
```

## 프롬프트 실습

```text
너는 친절한 AI 학습 코치야.
나는 AI 활용을 처음 공부하고 있어.
좋은 프롬프트를 만드는 핵심 원칙을 초보자 기준으로 설명해줘.
결과는 한 줄 요약, 쉬운 설명, 예시, 연습 문제 순서로 작성해줘.
```

```text
아래 프롬프트를 더 좋은 프롬프트로 바꿔줘.
역할, 목표, 맥락, 제약 조건, 출력 형식이 드러나게 개선해줘.
그리고 왜 그렇게 바꿨는지도 설명해줘.

프롬프트:
AI 활용법 알려줘.
```

## 실행 결과 예시

```text
한 줄 요약: 좋은 프롬프트는 AI가 해야 할 일과 답변 형식을 분명하게 알려주는 지시문이다.

쉬운 설명:
AI에게 그냥 "정리해줘"라고 말하면 기준이 애매하다.
하지만 누가 읽을지, 어떤 목적이 있는지, 어떤 형식으로 받을지 알려주면 결과가 훨씬 안정적이다.

개선 전:
AI 활용법 알려줘.

개선 후:
너는 초보자를 가르치는 AI 활용 코치야.
나는 공부 기록과 글쓰기, 코딩 보조에 AI를 활용하고 싶어.
먼저 꼭 알아야 할 원칙 5가지를 예시와 함께 설명해줘.
결과는 표로 정리해줘.
```
