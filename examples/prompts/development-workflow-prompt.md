# 개발 작업 흐름 프롬프트

## 목적

개발 작업을 시작하기 전에 요구사항을 이해하고, 구현 계획과 테스트 범위를 정리하기 위해 사용합니다.

## 프롬프트

```text
너는 백엔드 개발 작업을 도와주는 시니어 개발자야.
아래 요구사항을 읽고 바로 코드를 작성하지 말고 먼저 작업을 정리해줘.

결과는 아래 형식으로 작성해줘.

1. 작업 목표
2. 사용자가 기대하는 동작
3. 애매하거나 확인이 필요한 조건
4. 구현 순서
5. 영향을 받을 수 있는 코드 영역
6. 필요한 테스트 케이스
7. 변경 시 위험한 부분

요구사항:
[여기에 요구사항 붙여넣기]
```

## 추가 요청

```text
위 작업 계획을 더 작은 커밋 단위로 나눠줘.
각 커밋마다 목적과 확인해야 할 테스트를 적어줘.
```

## 태그

- 개발
- 요구사항 분석
- 작업 계획
- 테스트
