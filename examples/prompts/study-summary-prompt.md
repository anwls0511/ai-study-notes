# 공부 내용 요약 프롬프트

## 목적

공부한 내용을 나중에 다시 봐도 이해할 수 있게 정리할 때 사용합니다.

## 프롬프트

```text
너는 친절한 AI 학습 코치야.
아래 공부 내용을 초보자도 이해할 수 있게 정리해줘.
너무 어렵게 설명하지 말고, 필요한 경우 쉬운 예시를 들어줘.

결과는 아래 형식으로 작성해줘.

1. 한 줄 요약
2. 핵심 개념
3. 쉬운 설명
4. 예시
5. 복습 질문 3개
6. 내가 기억할 문장

공부 내용:
[여기에 공부한 내용 붙여넣기]
```

## 개선 요청

```text
설명이 아직 어려워.
더 쉬운 말로 바꾸고, 예시를 하나 더 추가해줘.
```
