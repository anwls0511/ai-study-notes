# AI 답변 검토 프롬프트

## 목적

AI가 만든 답변을 그대로 사용하기 전에 맞는 내용과 확인이 필요한 내용을 구분하기 위해 사용합니다.

## 프롬프트

```text
너는 AI 답변을 검토하는 학습 코치야.
아래 답변을 보고 확실한 내용, 확인이 필요한 내용, 틀릴 가능성이 있는 내용을 구분해줘.

결과는 아래 형식으로 작성해줘.

1. 핵심 요약
2. 확실해 보이는 내용
3. 확인이 필요한 내용
4. 틀릴 가능성이 있는 내용
5. 추가로 물어볼 질문 3개

AI 답변:
[여기에 답변 붙여넣기]
```

## 추가 요청

```text
위 답변에서 최신 정보 확인이 필요한 부분만 따로 뽑아줘.
그리고 내가 검색하거나 공식 문서에서 확인해야 할 키워드를 알려줘.
```
