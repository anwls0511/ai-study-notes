# 프롬프트 개선 프롬프트

## 목적

내가 작성한 프롬프트가 너무 애매할 때 더 좋은 프롬프트로 고치기 위해 사용합니다.

## 프롬프트

```text
너는 프롬프트 작성 코치야.
아래 프롬프트를 더 좋은 프롬프트로 개선해줘.
역할, 목표, 맥락, 제약 조건, 출력 형식이 잘 드러나게 바꿔줘.

결과는 아래 형식으로 작성해줘.

1. 기존 프롬프트의 문제점
2. 개선된 프롬프트
3. 왜 이렇게 바꿨는지
4. 추가로 더 좋아지게 만드는 질문

기존 프롬프트:
[여기에 프롬프트 입력]
```

## 예시 입력

```text
AI 활용법 알려줘.
```
