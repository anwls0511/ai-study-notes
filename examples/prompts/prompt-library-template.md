# 프롬프트 라이브러리 템플릿

## 목적

좋은 프롬프트와 개선 과정을 재사용 가능한 형태로 정리하기 위해 사용합니다.

## 템플릿

```md
# 프롬프트 이름

## 목적

이 프롬프트를 왜 사용하는지 적습니다.

## 사용 상황

언제 사용하면 좋은지 적습니다.

## 프롬프트

```text
여기에 실제 프롬프트를 적습니다.
```

## 결과 리뷰

- 좋았던 점:
- 부족했던 점:
- 다시 쓸 만한가:

## 개선 포인트

다음에 바꿔볼 내용을 적습니다.

## 태그

- 예: 공부
- 예: 개발
- 예: 요약
```

## 프롬프트 정리 요청

```text
아래 프롬프트를 내 프롬프트 라이브러리에 저장할 수 있게 정리해줘.
목적, 사용할 상황, 프롬프트, 결과 리뷰, 개선 포인트, 태그로 나눠줘.

프롬프트:
[여기에 프롬프트 붙여넣기]
```
