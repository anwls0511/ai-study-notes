# Practice 01. 요약 연습

## 목표

긴 내용을 AI로 요약하고, 다시 내 공부 기록으로 정리하는 연습입니다.

## 상황

블로그 글, 강의 내용, 공식 문서 일부를 읽고 핵심만 정리하고 싶을 때 사용합니다.

## 사용할 프롬프트

```text
아래 내용을 핵심 중심으로 요약해줘.
나는 초보자라서 쉬운 설명이 필요해.
결과는 아래 형식으로 작성해줘.

1. 한 줄 요약
2. 핵심 내용 5개
3. 쉬운 예시
4. 헷갈릴 수 있는 점
5. 내가 다음에 해볼 일

내용:
[요약할 내용]
```

## 개선 요청 프롬프트

첫 결과가 어렵거나 길면 아래처럼 다시 요청합니다.

```text
설명이 아직 조금 어려워.
더 쉬운 말로 바꿔주고, 예시를 하나 더 추가해줘.
그리고 마지막에 복습 질문 3개를 만들어줘.
```

## 기록할 것

- 어떤 내용을 요약했는가?
- AI가 잘 정리한 부분은 무엇인가?
- 부족했던 부분은 무엇인가?
- 내가 추가로 확인해야 할 사실은 무엇인가?
