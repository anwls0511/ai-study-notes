# Examples

AI를 실제로 활용한 사례를 기록합니다.

## Example Template

```md
# Title

## Situation

어떤 상황에서 AI를 사용했는지 적습니다.

## Prompt

사용한 프롬프트를 적습니다.

## Result

AI가 만든 결과를 요약합니다.

## Review

좋았던 점과 아쉬운 점을 정리합니다.

## Improved Prompt

개선한 프롬프트를 적습니다.
```

- 긴 글 요약하기
- 공부 내용 정리하기
- 블로그 글 초안 만들기
- 회의록 정리하기
- 코드 에러 설명 받기
- 아이디어 브레인스토밍하기
