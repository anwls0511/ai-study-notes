# 05. 일과 생활에서 AI 활용하기

## AI가 특히 잘 도와주는 일

AI는 아래와 같은 일에 강합니다.

- 긴 글 요약하기
- 초안 만들기
- 아이디어 많이 뽑기
- 문장 다듬기
- 표로 정리하기
- 체크리스트 만들기
- 코드 에러 설명하기
- 공부 계획 만들기

## AI에게 맡기기 좋은 일과 아닌 일

### 맡기기 좋은 일

- 초안 작성
- 반복적인 정리
- 다양한 아이디어 제안
- 문장 개선
- 학습 보조

### 조심해야 하는 일

- 법률, 의료, 금융처럼 정확성이 중요한 판단
- 최신 정보가 필요한 내용
- 개인정보가 들어간 자료 처리
- 사실 확인 없이 그대로 공개하는 글

## 실전 예시. 긴 글 정리

```text
아래 글을 읽고 핵심 내용을 정리해줘.
결과는 다음 형식으로 작성해줘.

1. 한 줄 요약
2. 핵심 내용 5개
3. 내가 바로 실행할 수 있는 행동 3개
4. 더 알아봐야 할 질문 3개

글:
[내용]
```

## 실전 예시. 문장 다듬기

```text
아래 문장을 더 자연스럽고 명확하게 다듬어줘.
의미는 바꾸지 말고, 너무 과장된 표현은 피해줘.

문장:
[문장]
```

## 핵심 정리

AI는 결과를 대신 완성해주는 마법 도구가 아니라, 생각의 속도를 높여주는 도구입니다. 좋은 활용자는 AI에게 일을 던지고 끝내는 사람이 아니라, 결과를 검토하고 개선해서 자기 결과물로 만드는 사람입니다.
