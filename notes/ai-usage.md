# AI Usage

AI를 도구로 잘 활용하기 위한 방법을 정리합니다.

## 핵심 원칙

- AI에게 역할을 명확히 준다.
- 원하는 결과물을 구체적으로 말한다.
- 필요한 맥락을 충분히 제공한다.
- 제약 조건을 미리 알려준다.
- 출력 형식을 지정한다.
- 첫 결과를 그대로 쓰기보다 개선 요청을 반복한다.

## 활용 분야

- 글쓰기
- 요약
- 번역
- 아이디어 정리
- 기획안 작성
- 코딩 보조
- 학습 도우미
- 업무 자동화

## 좋은 프롬프트 구조

```text
너는 [역할]이야.
내 목표는 [목표]야.
현재 상황은 [맥락]이야.
다음 조건을 지켜줘: [제약 조건]
결과는 [출력 형식]으로 작성해줘.
```

## 공부하면서 기록할 것

- 사용한 프롬프트
- 나온 결과
- 마음에 들었던 점
- 부족했던 점
- 개선한 프롬프트
