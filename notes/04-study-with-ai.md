# 04. AI로 공부하기

## AI를 공부 도우미로 쓰는 방법

AI는 선생님, 요약 도우미, 퀴즈 출제자, 복습 파트너로 사용할 수 있습니다. 중요한 것은 AI 답변을 그대로 믿는 것이 아니라, 이해를 돕는 도구로 쓰는 것입니다.

## 공부할 때 유용한 요청

### 쉬운 설명 요청

```text
아래 개념을 초보자도 이해할 수 있게 설명해줘.
먼저 한 문장으로 정의하고, 쉬운 예시를 들고, 마지막에 헷갈리기 쉬운 점을 알려줘.

개념:
[개념 입력]
```

### 복습 문제 요청

```text
아래 내용을 바탕으로 복습 문제 5개를 만들어줘.
문제는 쉬운 것부터 어려운 것 순서로 배치해줘.
각 문제 아래에는 정답과 해설을 적어줘.

내용:
[공부한 내용]
```

### 내 설명 검토 요청

```text
내가 아래처럼 설명해봤어.
틀린 부분, 애매한 부분, 더 쉽게 표현할 수 있는 부분을 알려줘.
그리고 개선된 설명도 작성해줘.

내 설명:
[내가 쓴 설명]
```

## AI로 공부할 때 조심할 점

- AI가 항상 정확한 것은 아닙니다.
- 중요한 사실은 공식 문서나 신뢰할 수 있는 자료로 확인해야 합니다.
- 이해하지 못한 내용을 그냥 복사하지 않습니다.
- AI에게 "왜 그런지"를 계속 물어보는 것이 좋습니다.

## 공부 기록 템플릿

```md
## 오늘 공부한 주제

## 헷갈린 부분

## AI에게 물어본 질문

## 다음에 공부할 것
```
