# 03. AI 워크플로우 만들기

## 워크플로우란?

워크플로우는 어떤 일을 처리하는 반복 가능한 순서입니다. AI 활용에서 중요한 것은 한 번 질문하고 끝내는 것이 아니라, 일을 처리하는 흐름을 만드는 것입니다.

## 기본 흐름

```text
1. 목표 정하기
2. 필요한 자료 모으기
3. AI에게 초안 요청하기
4. 결과 검토하기
5. 개선 요청하기
6. 최종본 정리하기
7. 배운 점 기록하기
```

## 예시 1. 글 요약 워크플로우

### 1단계. 원문 준비

요약할 글, 영상 자막, 문서 내용을 준비합니다.

### 2단계. 핵심 요약 요청

```text
아래 내용을 핵심만 요약해줘.
결과는 3줄 요약, 중요한 개념, 내가 기억해야 할 점으로 나눠줘.

내용:
[원문]
```

### 3단계. 이해 확인

```text
방금 요약한 내용을 내가 제대로 이해했는지 확인하고 싶어.
복습 질문 5개를 만들어줘.
각 질문 아래에는 정답도 함께 적어줘.
```

### 4단계. 내 말로 다시 정리

```text
위 내용을 내가 블로그에 기록할 수 있게 자연스러운 문장으로 정리해줘.
너무 길지 않게 작성해줘.
```

## 좋은 워크플로우의 특징

- 매번 다시 생각하지 않아도 됩니다.
- 결과물이 일정한 형식으로 쌓입니다.
- 실패한 부분을 개선하기 쉽습니다.
- 공부 기록과 실제 결과물이 함께 남습니다.

## 내 워크플로우 만들기 연습

1. 내가 자주 반복하는 일은 무엇인가?
2. 그 일에서 시간이 오래 걸리는 부분은 무엇인가?
3. AI가 도와줄 수 있는 부분은 무엇인가?
4. 결과를 어떤 형식으로 받고 싶은가?
5. 결과를 어떻게 검토할 것인가?
