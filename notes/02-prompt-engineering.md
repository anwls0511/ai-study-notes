# 02. 프롬프트 엔지니어링 기초

## 프롬프트 엔지니어링이란?

프롬프트 엔지니어링은 AI에게 원하는 결과를 얻기 위해 지시문을 설계하는 방법입니다. 어렵게 들리지만 핵심은 간단합니다.

> AI가 헷갈리지 않도록 원하는 일을 명확하게 설명하는 것

## 기본 공식

```text
너는 [역할]이야.
내 목표는 [목표]야.
현재 상황은 [맥락]이야.
다음 조건을 지켜줘: [제약 조건]
결과는 [출력 형식]으로 작성해줘.
```

## 예시 1. 공부 내용 정리

```text
너는 친절한 학습 코치야.
내 목표는 오늘 공부한 내용을 오래 기억하는 거야.
아래 내용을 초보자도 이해할 수 있게 정리해줘.
중요한 개념은 쉬운 예시를 들어 설명해줘.
결과는 핵심 요약, 자세한 설명, 복습 질문 3개로 작성해줘.

내용:
[여기에 공부한 내용 붙여넣기]
```

## 예시 2. 글쓰기 도우미

```text
너는 글쓰기 코치야.
나는 AI 활용 공부를 시작했다는 글을 블로그에 올리고 싶어.
읽는 사람은 AI를 처음 공부하는 사람이라고 가정해줘.
문장은 너무 딱딱하지 않게 써줘.
결과는 제목 후보 5개, 글 구조, 첫 문단 초안으로 나눠줘.
```

## 결과가 별로일 때 다시 요청하는 방법

첫 답변이 마음에 들지 않을 때는 "다시 해줘"보다 구체적으로 말하는 것이 좋습니다.

```text
좋아. 그런데 설명이 아직 어려워.
중학생도 이해할 수 있을 정도로 더 쉽게 바꿔줘.
그리고 예시를 하나 더 추가해줘.
```

```text
내용은 좋은데 너무 길어.
핵심만 5줄로 줄이고, 마지막에 내가 바로 실행할 행동 3개를 적어줘.
```

## 핵심 정리

- 프롬프트는 한 번에 완벽하게 쓰려고 하지 않아도 됩니다.
- 첫 결과를 보고 다시 개선하는 과정이 중요합니다.
- 역할, 목표, 맥락, 제약 조건, 출력 형식을 넣으면 결과가 안정됩니다.
- 좋은 프롬프트는 나중에 다시 쓸 수 있도록 저장해두는 것이 좋습니다.
