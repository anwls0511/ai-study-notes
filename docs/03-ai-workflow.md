# 세 번째 학습: AI 워크플로우

> 목표: AI에게 한 번 질문하고 끝내는 것이 아니라, 반복 가능한 작업 흐름으로 활용하는 방법을 이해한다.

## 오늘의 결론

```text
AI 워크플로우는 반복 작업을 처리하는 순서다.
목표를 정하고, 자료를 넣고, 초안을 받고, 검토하고, 개선하고, 최종 결과를 기록하는 흐름이다.
AI 활용 능력은 좋은 질문 하나보다 좋은 반복 흐름을 만드는 데서 더 크게 늘어난다.
```

## 한눈에 보기

| 단계 | 하는 일 |
| --- | --- |
| 목표 정하기 | 무엇을 만들고 싶은지 정한다 |
| 자료 넣기 | AI가 참고할 내용을 제공한다 |
| 초안 받기 | 처음 결과를 만든다 |
| 검토하기 | 맞는 내용과 부족한 내용을 확인한다 |
| 개선하기 | 더 쉽게, 더 짧게, 더 구체적으로 다시 요청한다 |
| 기록하기 | 최종 결과와 배운 점을 남긴다 |

## 1. 오늘 이걸 공부한 이유

AI를 잘 활용하려면 매번 새롭게 고민하지 않아도 되는 흐름이 필요하다.

예를 들어 공부 내용을 정리할 때마다 매번 다른 방식으로 질문하면 기록이 들쑥날쑥해진다. 반대로 정해진 흐름이 있으면 결과가 일정하게 쌓인다.

## 2. 공부 정리 워크플로우

공부 내용을 정리할 때는 아래 순서를 사용할 수 있다.

```text
1. 공부한 내용을 붙여넣는다.
2. 핵심 요약을 요청한다.
3. 쉬운 설명과 예시를 요청한다.
4. 복습 질문을 요청한다.
5. 내 말로 정리할 문장을 요청한다.
6. GitHub에 학습 기록으로 남긴다.
```

사용할 프롬프트는 다음과 같다.

```text
아래 공부 내용을 정리해줘.
나는 초보자라서 쉬운 설명이 필요해.
결과는 한 줄 요약, 핵심 내용 5개, 쉬운 예시, 복습 질문 3개, 내가 기억할 문장 순서로 작성해줘.

내용:
[공부한 내용]
```

## 3. 글쓰기 워크플로우

글을 쓸 때는 AI에게 바로 완성본을 요구하기보다 구조부터 잡는 것이 좋다.

```text
1. 주제와 독자를 정한다.
2. 제목 후보를 받는다.
3. 글 구조를 받는다.
4. 첫 문단 초안을 받는다.
5. 문체를 조정한다.
6. 최종 글을 직접 검토한다.
```

## 4. 결과 검토 체크리스트

AI가 만든 결과는 아래 기준으로 확인한다.

```text
사실이 맞는가?
내 상황과 맞는가?
너무 일반적이지 않은가?
바로 실행할 수 있는가?
불필요하게 긴 부분은 없는가?
내 말투와 맞는가?
```

## 5. 설명할 수 있는 문장

AI 워크플로우에 대해서는 이렇게 설명할 수 있다.

> AI 워크플로우는 목표 설정, 자료 제공, 초안 생성, 검토, 개선, 기록까지 이어지는 반복 가능한 작업 흐름입니다. 한 번의 좋은 질문보다 이런 흐름을 만들어두는 것이 공부나 업무에서 AI를 안정적으로 활용하는 데 더 도움이 됩니다.
