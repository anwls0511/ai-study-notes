# 첫 번째 학습: AI 활용 기초

> 목표: AI를 단순한 답변 기계가 아니라, 내 생각과 작업을 도와주는 문제 해결 도구로 이해한다.

## 오늘의 결론

```text
AI를 잘 쓴다는 것은 질문을 한 번 잘 던지는 것이 아니다.
내 목표를 분명히 하고, 필요한 맥락을 주고, 결과를 검토한 뒤 다시 개선하는 과정이다.
좋은 AI 활용은 역할, 목표, 맥락, 제약 조건, 출력 형식을 분명히 전달하는 것에서 시작한다.
```

## 한눈에 보기

| 개념 | 오늘 이해한 내용 |
| --- | --- |
| AI 활용 | AI에게 일을 맡기는 것이 아니라, 내가 원하는 결과를 만들기 위해 AI를 도구로 쓰는 것 |
| 역할 | AI가 어떤 관점으로 답해야 하는지 정하는 것 |
| 목표 | 내가 최종적으로 얻고 싶은 결과 |
| 맥락 | 현재 상황, 수준, 배경 정보 |
| 출력 형식 | 답변을 표, 목록, 단계별 설명처럼 어떤 모양으로 받을지 정하는 것 |

## 1. 오늘 이걸 공부한 이유

AI에게 질문했는데 답변이 마음에 들지 않을 때가 많다.

```text
설명이 너무 일반적이다.
내 상황과 맞지 않는다.
답변은 길지만 바로 쓰기 어렵다.
중요한 내용과 덜 중요한 내용이 섞여 있다.
```

이 문제는 AI 성능만의 문제가 아니다. AI에게 무엇을 해야 하는지 충분히 알려주지 않았기 때문에 생기는 경우가 많다.

## 2. AI에게 꼭 알려줘야 하는 것

AI에게 좋은 결과를 받으려면 최소한 다섯 가지를 알려주는 것이 좋다.

```text
역할: 너는 어떤 입장에서 답해야 하는가?
목표: 나는 무엇을 얻고 싶은가?
맥락: 현재 상황은 어떤가?
제약 조건: 지켜야 할 조건은 무엇인가?
출력 형식: 어떤 형태로 답해야 하는가?
```

예를 들어 그냥 이렇게 말하면 답변이 넓고 애매해진다.

```text
AI 활용법 알려줘.
```

하지만 아래처럼 말하면 훨씬 구체적인 답변을 받을 수 있다.

```text
너는 초보자를 가르치는 AI 활용 코치야.
나는 공부 기록, 글쓰기, 코딩 보조에 AI를 활용하고 싶어.
먼저 꼭 알아야 할 원칙 5가지를 알려줘.
각 원칙마다 나쁜 예시와 좋은 예시를 같이 보여줘.
```

## 3. AI 답변은 초안이다

AI가 만든 답변은 최종본이 아니라 초안이라고 생각하는 것이 좋다.

```text
1. AI에게 초안을 받는다.
2. 내가 읽고 부족한 점을 찾는다.
3. 더 쉽게, 더 짧게, 더 구체적으로 다시 요청한다.
4. 최종 결과를 내 말로 정리한다.
```

이 과정을 거치면 AI가 대신 만든 결과가 아니라, 내가 검토하고 완성한 결과물이 된다.

## 4. 바로 써볼 프롬프트

```text
너는 친절한 AI 학습 코치야.
나는 AI 활용을 처음 공부하고 있어.
AI를 잘 쓰기 위해 꼭 알아야 할 기본 원칙 5가지를 알려줘.
각 원칙마다 쉬운 설명과 예시를 포함해줘.
마지막에는 오늘 바로 해볼 연습 문제 3개를 만들어줘.
```

## 5. 설명할 수 있는 문장

AI 활용 기초에 대해서는 이렇게 설명할 수 있다.

> AI를 잘 활용한다는 것은 AI에게 모든 것을 맡기는 것이 아니라, 내가 원하는 목표와 맥락을 분명히 전달하고 나온 결과를 검토해 개선하는 과정입니다. 좋은 프롬프트에는 역할, 목표, 맥락, 제약 조건, 출력 형식이 들어가야 답변이 더 안정적입니다.
