# 네 번째 학습: AI 답변 검토와 사실 확인

> 목표: AI가 만든 답변을 그대로 믿지 않고, 맞는 내용과 확인이 필요한 내용을 구분할 수 있게 된다.

## 오늘의 결론

```text
AI 답변은 항상 최종 정답이 아니라 검토해야 할 초안이다.
AI가 그럴듯하게 말해도 틀릴 수 있다.
중요한 정보는 근거, 출처, 최신성, 내 상황과의 관련성을 기준으로 확인해야 한다.
```

## 한눈에 보기

| 개념 | 오늘 이해한 내용 |
| --- | --- |
| AI 답변 검토 | AI가 만든 답변을 그대로 쓰기 전에 맞는지 확인하는 과정 |
| 환각 | AI가 사실이 아닌 내용을 그럴듯하게 말하는 현상 |
| 근거 확인 | 답변이 어떤 기준이나 자료에 기반했는지 확인하는 것 |
| 최신성 확인 | 정보가 현재도 유효한지 확인하는 것 |
| 재질문 | 부족한 답변을 더 정확하게 만들기 위해 다시 묻는 것 |

## 1. 오늘 이걸 공부한 이유

AI는 답변을 매우 자연스럽게 만든다. 그래서 틀린 내용도 맞는 것처럼 보일 수 있다.

```text
설명이 자연스럽다.
문장이 자신감 있어 보인다.
표나 목록으로 정리되어 있어 믿음직해 보인다.
하지만 실제로는 틀린 내용이 섞여 있을 수 있다.
```

그래서 AI를 잘 활용하려면 답변을 받는 능력만큼 답변을 검토하는 능력이 필요하다.

## 2. AI 답변을 검토하는 기준

AI 답변을 볼 때는 아래 기준으로 확인한다.

```text
1. 사실이 맞는가?
2. 근거가 있는가?
3. 최신 정보가 필요한 내용인가?
4. 내 상황에 맞는가?
5. 너무 일반적인 답변은 아닌가?
6. 빠진 조건은 없는가?
```

## 3. 위험한 답변의 특징

아래와 같은 답변은 조심해야 한다.

```text
출처 없이 단정적으로 말한다.
최신 정보가 필요한데 날짜가 없다.
내 상황을 모르는데 확정적으로 추천한다.
전문 분야인데 너무 쉽게 결론을 낸다.
장점만 말하고 한계나 예외를 말하지 않는다.
```

## 4. 다시 물어보는 방법

AI 답변이 애매하면 이렇게 다시 물어볼 수 있다.

```text
방금 답변에서 확실한 사실과 추측을 구분해줘.
최신 정보 확인이 필요한 부분을 따로 표시해줘.
틀릴 가능성이 있는 부분과 추가로 확인해야 할 내용을 알려줘.
```

## 5. 바로 써볼 프롬프트

```text
아래 AI 답변을 검토해줘.
확실한 내용, 확인이 필요한 내용, 틀릴 가능성이 있는 내용을 구분해줘.
그리고 내가 추가로 확인해야 할 질문 3개를 만들어줘.

AI 답변:
[여기에 AI 답변 붙여넣기]
```

## 6. 설명할 수 있는 문장

AI 답변 검토에 대해서는 이렇게 설명할 수 있다.

> AI 답변은 자연스럽고 그럴듯해 보여도 항상 맞는 것은 아닙니다. 그래서 중요한 내용은 사실 여부, 근거, 최신성, 내 상황과의 관련성을 기준으로 확인해야 합니다. AI를 잘 활용하려면 답변을 받는 것뿐 아니라 답변을 검토하고 다시 질문하는 능력이 필요합니다.
